## Dates and routes

- Use Temporal from `temporal-polyfill` for all date/time calculations, comparisons, calendar arithmetic, and formatting. Node 24 and browsers may lack native Temporal. Use PlainDate for calendar dates and Instant for timestamps; state time zones explicitly when converting between them. Date is allowed only at Prisma/serialization boundaries; do not calculate with Date or Date.now(). Shared helpers live in src/lib/dates.ts.
- Write all internal application URLs with the generated `app` helpers from `@/lib/routes`, generated by `@eliyya/type-routes`. Run `routes:generate` when adding/removing routes. Use APP_URL as the base for absolute server redirects behind a proxy. External URLs, asset paths, route matcher patterns and Next.js route type declarations are exceptions.
- Billing cut days are inclusive. Name each period using the month containing the most days and a two-digit year; ties use the starting month.
